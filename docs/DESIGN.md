# DESIGN.md

## Visual & Theme Guidelines
- **Color Palette**:
  - Primary Accent: Duolingo-inspired Flame Amber (`#FF6D00` / `#FFAB40`)
  - Freeze Accent: Icy Frost Blue (`#00E5FF` / `#80DEEA`)
  - Backgrounds: Dark Mode Sleek (`#121212` / `#1E1E1E`) & Light Mode Fresh (`#F8F9FA` / `#FFFFFF`)
- **Typography**: Clean modern typography with high contrast counts.
- **Card Layout**: Actionable/incomplete habits pinned to top of home feed.
- **Micro-Animations**: Smooth visual feedback on habit completion and freeze badge status.
